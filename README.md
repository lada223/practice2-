# Практическая работа №2: Программный маршрутизатор и многоклиентская сеть

## 📌 Описание проекта
Данный проект представляет собой программную модель компьютерной сети на Python. 
В отличие от первой работы (Клиент → Сервер), здесь реализована более сложная архитектура с центральным узлом — **программным маршрутизатором**, который обслуживает несколько клиентов, разделённых на логические подсети, и поддерживает работу с двумя транспортными протоколами.

### Схема сети
```text
       Подсеть 1 (192.168.1.0/24)             Подсеть 2 (192.168.2.0/24)
       ┌──────────────┐                       ┌──────────────┐
       │   Client1    │ (TCP)                 │   Client4    │ (UDP)
       │   Client2    │ (TCP)                 │   Client5    │ (UDP)
       │   Client3    │ (TCP)                 │   Client6    │ (UDP)
       └──────┬───────┘                       └──────┬───────┘
              │                                      │
              │ TCP : 5000                           │ UDP : 6000
              ▼                                      ▼
       ┌─────────────────────────────────────────────────┐
       │                   ROUTER                        │
       │          (Анализ сообщений и маршрутизация)     │
       └─────────────────────────────────────────────────┘
